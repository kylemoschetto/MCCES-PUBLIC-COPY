Generation Steps Detail

AI Generation Phase

Each step processes content in batches to stay within context limits and ensure quality output.

1 Task Extraction

Identifies discrete tasks, procedures, and skills from source content. Forms the foundation for all subsequent curriculum generation.

Input: Document chunks
Output: Task list with descriptions
Batching: By document section

2 T&R Events

Maps extracted tasks to Training and Readiness (T&R) event codes. Aligns curriculum with USMC training standards.

Input: Extracted tasks
Output: T&R event mappings
Batching: By task group

3 Terminal Learning Objectives

Generates high-level learning objectives that define overall competency goals. Uses Bloom's taxonomy action verbs.

Input: Tasks + T&R events
Output: TLO statements
Batching: By T&R event group

4 Enabling Learning Objectives

Creates subordinate objectives that support each TLO. Breaks down learning into measurable, teachable units.

Input: TLOs + source content
Output: ELO statements per TLO
Batching: By TLO

5 MLF Data

Generates Master Lesson File data including methods, media, and references. Provides instructional guidance for each objective.

Input: TLOs + ELOs + content
Output: MLF records
Batching: By ELO group

6 WIIFM Checklists

Generates "What's In It For Me" checklists with 7 categories (21 questions) that help instructors justify why training matters to Marines.

Input: TLOs + MLF content
Output: WIIFM checklists per TLO
Batching: By TLO (2 per batch)

7 Quiz Questions

Creates assessment questions aligned to each ELO. Includes multiple choice with rationales for correct and incorrect answers.

Input: ELOs + source content
Output: Quiz items per ELO
Batching: By ELO
